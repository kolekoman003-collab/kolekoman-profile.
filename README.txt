PERSONAL PORTFOLIO TEMPLATE

Files:
- index.html  : page content + placeholder personal/project/education info
- style.css   : glassmorphism + neon visual design, responsive
- script.js   : Persian/English switch, dark/light mode, WhatsApp + phone + Instagram + email links

CUSTOMIZE:
1) Open script.js and edit PROFILE (name, phone, Instagram, email, WhatsApp message).
2) Open index.html and replace the education/project placeholder text as needed.
3) Put any project screenshots in assets/ and, if desired, replace the generated project visuals in index.html with <img src="assets/your-image.jpg">.
4) Open index.html directly, or deploy the folder to GitHub Pages / Netlify / Vercel.

WhatsApp number must be in international format without + or spaces in PROFILE.phoneIntl.
